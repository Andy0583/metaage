### **<font color="red">AI Server安裝八張GPU時，無法偵測到GRAID卡</font>** 
**Issue** 

- 安裝SupremeRAID pre-installer 後，於`nvidia-smi`無法找到GRAID卡
- 使用`dmesg` 呈現下列資訊
  ```
  QuoteNVRM: This PCI I/O region assigned to your NVIDIA device is invalid:
  NVRM: BAR0 is 0M @ 0x0 (PCI:0001:05:00.0)
  nvidia: probe of 0001:05:00.0 failed with error -1
  ```

**Cause**

- Linux 核心可能會在啟動期間重新分配 PCI 資源，某些裝置可能會收到錯誤或大小為零的 BAR 分配（例如，BAR0 = 0M），導致 RAID 卡無法被偵測到
- 非每種GPU卡都會遇到。

**Resolution**

- 透過在 GRUB 配置中新增以下參數，停用啟動期間的 PCI 資源重新分配
- 適用於 Ubuntu / Debian 的步驟
  ```
  # 編輯 GRUB 設定
  sudo nano /etc/default/grub
  
  # 新增pci=realloc=off至該GRUB_CMDLINE_LINUX行（追加至現有參數）
  GRUB_CMDLINE_LINUX="quiet splash pci=realloc=off"
  
  # 更新 GRUB
  sudo update-grub
  
  # 重啟系統
  sudo reboot
  ```

- 適用於 RHEL / Rocky / AlmaLinux 的步驟
  ```
  # 編輯 GRUB 設定
  sudo nano /etc/default/grub
  
  # 新增pci=realloc=off到內核命令列
  GRUB_CMDLINE_LINUX="... pci=realloc=off"
  
  # 重建 GRUB 設定（UEFI 範例）
  （對於 BIOS 模式，請使用/boot/grub2/grub.cfg。）
  sudo grub2-mkconfig -o /boot/efi/EFI/redhat/grub.cfg
  
  # or for Rocky / Alma
  sudo grub2-mkconfig -o /boot/efi/EFI/rocky/grub.cfg
  sudo grub2-mkconfig -o /boot/efi/EFI/almalinux/grub.cfg
  
  # 重啟系統
  sudo reboot
  ```
